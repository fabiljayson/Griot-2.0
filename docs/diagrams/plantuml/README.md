## 🛠️ How to Use

### Visual Paradigm
1. Open Visual Paradigm
2. Go to **File > Import > PlantUML**
3. Select the `.puml` file
4. The diagram will be imported and can be converted to native VP format

### PlantUML Server
1. Copy the content of any `.puml` file
2. Paste into [plantuml.com/plantuml](https://www.plantuml.com/plantuml/uml/)
3. Export as PNG, SVG, or PDF

### Command Line
```bash
# Install PlantUML
java -jar plantuml.jar

# Render a diagram
java -jar plantuml.jar 01-use-case-diagram.puml
```

### VS Code Extension
Install the **PlantUML** extension (`jebbs.plantuml`) to preview diagrams.
